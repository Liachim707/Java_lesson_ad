# Java + OpenCV: поиск элементов интерфейса по шаблону

## Описание проекта

Проект демонстрирует автоматизацию пользовательского интерфейса на Java с помощью **OpenCV** и **java.awt.Robot**.

При запуске открывается небольшое окно калькулятора. Программа делает снимки кнопок и сохраняет их как PNG-шаблоны в папку `templates/`. Затем OpenCV ищет изображения кнопок на экране, а `Robot` нажимает найденные кнопки. После выполнения последовательности программа проверяет отображаемый результат.

В проекте есть два сценария из задания:

1. **Позитивный:** нажимаются `1`, `2`, `+`, `3`, `=`. Ожидаемый и фактический результат — `15`.
2. **Негативный:** нажимаются `1`, `2`, `+`, `4`, `=`, но ожидаемое значение намеренно оставлено `15`. Фактический результат — `16`, поэтому программа выводит `НЕСОВПАДЕНИЕ`. Это ожидаемое поведение негативного сценария, а не ошибка приложения.

## Что реализовано

- Метод `find(String templateFile, double accuracy, Rectangle searchArea)` принимает имя PNG-шаблона, порог совпадения от `0.0` до `1.0` и область экрана для поиска.
- Если область поиска равна `null`, поиск выполняется по всему экрану.
- Координаты найденного шаблона переводятся из координат области поиска в экранные координаты.
- Перед поиском проверяется, что шаблон и снимок экрана успешно загружены, а шаблон не больше области поиска.
- Вызов `Imgproc.matchTemplate` использует метод `TM_CCOEFF_NORMED`.
- Шаблоны кнопок автоматически создаются при старте приложения в папке `templates/`.

## Требования

- Windows 10/11 или другая настольная ОС с графическим интерфейсом.
- JDK 17 или новее.
- Apache Maven 3.8+.
- Подключение к интернету при первой сборке для загрузки Maven-зависимостей.
- Экран с масштабированием Windows желательно установить на 100% или 125%; окно калькулятора не следует перекрывать во время выполнения.

OpenCV подключён через Maven-зависимость `org.openpnp:opencv`; нативная библиотека загружается методом `OpenCV.loadLocally()`.

## Запуск

Откройте терминал в корневой папке репозитория и выполните:

```bash
mvn clean compile
mvn exec:java
```

После запуска:

1. Откроется окно демонстрационного калькулятора.
2. В корне проекта появится папка `templates/` с PNG-изображениями кнопок `1`, `2`, `3`, `4`, `+`, `=` и `C`.
3. Программа выполнит позитивный и негативный сценарии и выведет сравнение ожидаемого и фактического результата в консоль.

Для повторного запуска используйте `mvn exec:java`. Шаблоны обновляются при каждом запуске, чтобы соответствовать фактическому виду кнопок на экране.

## Пример ожидаемого вывода

Точные строки о создании файлов и координатах зависят от компьютера. Основная часть вывода будет выглядеть так:

```text
Проверка правильного результата
Ожидалось: 15 | Получено: 15 | Результат: УСПЕХ

Проверка намеренно неверного ожидания
Ожидалось: 15 | Получено: 16 | Результат: НЕСОВПАДЕНИЕ
```

## Важно

Это демонстрационный тест с собственным Swing-калькулятором, поэтому шаблоны кнопок создаются из реально отображаемого окна и не зависят от темы или версии стандартного приложения Windows Calculator. Во время выполнения не перемещайте окно и не перекрывайте его другими окнами.

Сценарии используют экранные координаты и `Robot`, поэтому запуск требует активного рабочего стола. В среде без графического интерфейса (например, headless CI) программа не запустится.
